# 경제성 모형 수정 메모 (2026-11-20)

`econ_model.py` 세 군데를 고치고 `python econ_model.py --all --workers 8`로 전체를 다시 돌렸다
(본 실행 77건, 민감도 43건, BIPV·연차검증 28건, 실패 0건). 기준 커밋은 95c3354이다.
`results/econ/*.csv`는 이 수정본의 결과로 교체되었다.

## 1. 무엇을 바꿨나

### (1) 기준 시간대: split → 1년 전체 개편 후

- `TOU_BASE = "new"`를 신설하고 `solve`, `baseline`, `evaluate`, `bipv_and_check`의 기본 시간대를 이것으로 바꿨다
- 이유: 사업은 2027년 이후 운영되므로 평가 기간 전체가 개편 후 시간대다. split(2026-06-01 전후 분리)은
  분석 창 364일 중 270일이 개편 전이라 과거 요금체계에 지배된다
- split은 `--validate`(과거 고지액 재현)와 재최적화 민감도 한 줄(`시간대_split`)로만 남겼다.
  종전 민감도 `시간대_개편후`는 없앴다(이제 기준이므로)
- duration 스윕, PV 비율 스윕, 민감도, BIPV가 모두 개편 후 기준으로 나온다

### (2) PV 공사비: 시나리오별 단가 → 공통 단가 + 국비 인정 상한

- `PV_COST = 1,300,000원/kW`를 A, C-1, C-2에 똑같이 적용한다
- 공고의 1,036,000원/kW는 `PV_ELIG_CAP`으로 두고 국비 산정에만 쓴다.
  `subsidy_split`의 PV 적격단가 = min(실제 공사비, 인정 상한) + 진단비
- 이유: 종전에는 C-1·C-2에만 103.6만원을 공사비로 써서, 제약이 더 많은 C-1의 NPV가 A보다 높게 나왔다.
  공고가 공사비를 낮추는 것은 아니므로 그 차이는 시나리오 효과가 아니라 단가 가정의 차이였다
- 공사비 103.6만원(종전 C 가정)과 150만원은 사후 민감도 행으로 전 시나리오에 넣었다
  (`PV 공사비 103.6만(공고 상한)`, `PV 공사비 150만`). 종전 `A 시장단가 150만` 행은 없앴다
- `PV_PRICE`, `PV_PRICE_A_HIGH`는 `ess_pv_pipeline.ipynb` 호환용 별칭으로만 남겼다
- 이제 A(최적 h) → A(5h) = 5시간 요건 효과, A(5h) → C-1 = 충전의무 효과, C-1 → C-2 = 국비 효과로 읽는다

### (3) 결과 열 보완 (`main.csv`, `sens_rerun.csv`, `sens_posthoc.csv`)

- `피크_1년차` → `전시간최대_1년차`로 이름을 바꿨다. 이 값은 전 시간 최대이고, 기본요금은
  중간·최대부하 시간대 피크(요금적용전력)로 매기므로 서로 다르다
- 추가한 열: `적용전력합_1년차`, `기본요금_1년차`, `전력량요금_1년차`,
  `절감_1년차_기본요금`, `절감_1년차_전력량등`, `PV_기본요금절감`, `PV_전력량등절감`
  (기본요금 절감은 세후 금액이며 전기요금 절감의 일부다)
- `NPV_총사업비관점`(같은 설계를 국비 없이 평가)을 C-2뿐 아니라 전 시나리오에 넣었다

## 3. 수정 전후 결과 (PV 100%, 억원)

| | 수정 전 (split, C만 103.6만) | 수정 후 (개편 후, 130만 공통) |
| --- | --- | --- |
| A 1h (ESS 1,034kW) | 138.24 | 133.60 |
| A 5h | 131.48 (ESS 0) | 126.85 (ESS 0) |
| C-1 | 158.69 (ESS 0) | 126.85 (ESS 0) |
| C-2 | 242.84 (ESS 0, 국비 84.15) | 212.17 (ESS 2,101kW, 국비 117.22) |
| C-2 총사업비 관점 | 158.69 | 94.95 |

- 5시간 요건 효과 −6.75억, 충전의무 효과 0(5h에서 ESS가 이미 0), 국비 효과 +85.33억
- 국비 117.22억 중 31.89억은 5시간 ESS의 손실을 메우는 데 쓰인다(94.95 − 126.85)
- 1h ESS 증분 +6.75억, 2h +2.00억, 3~5h는 설치하지 않음. 5h(C-2 설계)는 국비 전 −31.90억, 국비 후 +1.18억
- 절감액 중 기본요금 몫: A 1h ESS 90%(15.99억 중 14.46억), C-2 5h ESS 71%(41.15억 중 29.40억)
- 요금적용전력 합의 감소가 ESS 출력 × 12개월과 일치한다(C-2: 25,207kW = 2,100.6 × 12).
  2,100.6kW는 PCS 상한(20,000kW)이나 예산 한도(약 2,912kW에서 구속)에 걸린 값이 아니다
- PV는 개편 후 기준에서도 0~100% 전 구간에서 NPV가 늘어 상한이 최적이다
- 개편 후 C-2의 ESS는 교체비 15만원, PCS 정비 30%, 열화비 10원 중 하나만 넣어도 0kW가 된다

## 4. 적용할 때 주의

- 엑셀 추출 스크립트 등에서 `피크_1년차` 열을 쓰는 곳은 `전시간최대_1년차`로 바꿔야 한다
- 민감도 이름이 바뀌었다: `시간대_개편후` → `시간대_split`, `A 시장단가 150만` → `PV 공사비 150만`
- `meta.csv`의 연차 보간 검증 대상이 A 1h에서 C-2(ESS가 가장 큰 설계)로 바뀌었다(차이 0.057억)
- `README.md`, `reference/economics.md`, `reference/parameters.md`는 이번에 고치지 않았다.
  그 문서의 결과 수치와 시나리오 설명(C의 PV 단가 103.6만원)은 종전 기준이다

## 5. 아직 하지 않은 것

- 충전의무를 공고의 사후관리 기간(5년)으로 한정하고 수준(0 / 0.5 / 1.0)을 범위로 보고
- ESS 크기를 격자로 고정해 운전만 풀고, 국비율·예산 한도·BOS 배분을 사후 계산으로 처리
- PV 발전량 민감도(모형이 발표자료 기준보다 6.1% 높음), 인버터 교체비
- 예측 기반 운전과 다년 자료로 최대수요 삭감 효과 검증
  (1,034kW 삭감이 필요한 날은 기준 부하 5일, 실측 부하 6일이고 대부분 2026년 8월 첫 주다)
