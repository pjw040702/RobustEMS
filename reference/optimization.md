# ESS·PV 최적화 설계

9개 기후 시나리오(present + SSP1-2.6/2-4.5/3-7.0/5-8.5 × 2030s/2050s) 각각에 대해 1년 운영비용을
최소화하는 디스패치 LP를 독립적으로 풀고 결과를 비교한다. ESS 용량(`C_ESS`/`C_PCS`)은 고정이고
**PV 설치용량(`C_PV`)은 결정변수**다.

파라미터 값과 출처는 `parameters.md`가 단일 진실 공급원이다.

## 목적함수

$$C_s = E_s + D_s + G_s + K_s + P_s$$

**$E_s$ 전력량요금**

$$E_s=\sum_t \pi_t\, P_{grid,t}\,\Delta t,\qquad \pi_t=(Tariff_t + 9 + 5)\times 1.132$$

TOU 요금(경부하/중간/최대 × 계절)에 기후환경요금 9원/kWh + 연료비조정요금 5원/kWh을 더하고
전력산업기반기금 3.2% + 부가세 10%(×1.132)를 곱한다. **학교가 실제로 내는 청구서 구조**이고,
**PV 자가발전분은 이 부가 항목이 전부 면제**되므로 빼면 PV 편익이 과소평가된다.

**$D_s$ 기본요금(피크)**

$$D_s = 12 \times 1.132 \times c_{peak} \times P_{peak,s}$$

$c_{peak}$=6,980원/kW는 교육용(을) 고압A의 **월** 단가이므로 연간 환산에 **×12**가 붙는다
(래칫: 연중 최대피크가 12개월 적용). `P_peak,s ≥ P_grid,t,s` (연중 전체 $t$) 제약으로 max()를
선형화한다 → **15분 피크전력이 비용에 직접 반영된다.**

**$G_s$ 열화비용 (cycle aging만)**

$$G_s = c_{deg}\sum_t (P_{ch,t,s}+P_{dis,t,s})\Delta t,\qquad
c_{deg}=\frac{c_{bat,replacement}}{2N_{EFC}}=\frac{100{,}000}{2\times 5{,}000}=10\ \text{원/kWh}$$

최적화 단계는 이 throughput 선형 근사만 쓴다. 산출된 SOC 시계열은 **Rainflow counting +
Miner's Rule**로 실제 수명을 사후 검증하며 LP 목적함수에는 포함하지 않는다(지도교수 자문).
Calendar aging은 운전 결정과 거의 무관(경과시간 위주)해 LP에서 제외하고, 전체 경제성 평가에서
$C_{calendar}\approx c_{bat,replacement}\times t/L_{calendar}$ ($L_{calendar}$≈10년)로 별도
고정비용으로 반영한다.

사후검증 결과 괴리율은 **−0.43%**(45개 조합 전부)이고 사이클 기준 수명은 **30.0~30.4년**으로
calendar 10년을 크게 넘는다. 따라서 (a) `N_EFC` 민감도는 비구속이므로 우선순위를 내리고,
(b) 교체비를 10년 연간환산으로 경제성에 넣는다면 `c_deg`를 비용 합계에 다시 더하는 것은
**이중계산**이다 — 조원 모델의 "`c_deg`는 운전 판단에만, 합계에서 제외" 처리가 타당하다.

**$K_s$ 탄소비용**

$$K_s = \frac{\sum_t P_{grid,t,s}\Delta t}{1000}\times CO_2^{factor}\times CARBON^{price}$$

배출계수 0.45941 tCO2eq/MWh, 가격 25,500원/tCO2(발표자료 p.30 SKKU 실적 단가). 타 마이크로그리드
연구 대비 차별점이라 지도교수가 목적함수 포함을 지시했다. 51·76 USD 민감도를 병기한다.
계약·환경가치 반영 배출계수와 한계배출계수는 검토했으나 범위 밖으로 확인되어 쓰지 않는다.

여기 들어가는 값은 **배출권(허가증) 비용**이다. 탄소의 **사회적 비용(SCC)**은 성격이 다르므로
목적함수에 넣지 않고 서술에서 구분만 한다.

**$P_s$ PV 설비 연간비용**

$$P_s = c_{pv,annual}\times C_{PV},\qquad
c_{pv,annual}=\frac{2{,}021{,}531+29{,}443}{25}+59{,}809=141{,}848\ \text{원/kW/년}$$

발표자료 p.53 기준 순설비비 + 구조안전진단을 25년으로 분할하고 O&M을 더한다.

## 제약식

- 전력수지: `P_grid − P_curt + P_dis − P_ch + C_PV·p_unit,t = P_load`
  ($p_{unit,t}$ = 1kW 설치 시 단위발전량)
- SOC 동역학(자기방전 포함) + SOC 범위 20~90%, 상태변수는 $T{+}1$개
- 충방전 출력 상한 `≤ C_PCS`
- 피크 보조변수 선형화: `P_peak ≥ P_grid,t` (∀t, 연중 전체)
- PV curtailment 상한: `P_curt,t ≤ C_PV·p_unit,t`
- PV 설비용량 상한: `0 ≤ C_PV ≤ C_PV^max` (0·1단계는 고정값으로 대체)

동시 충방전 금지는 이진변수 제약이지만 효율손실($\eta<1$)로 자연히 발생하지 않음을 검증(위반
0건)해 **구현하지 않고 순수 LP로 푼다.**

## 설비용량 시나리오

발표자료 p.41의 자과캠 PV 설치계획(`reference/campus_pv_potential.csv`)을 상한으로 사용한다.

| 단계 | `C_PV` 범위 | 근거 |
| --- | --- | --- |
| 0. PV없음 | 0 kW 고정 | **자과캠 현재 상태.** 탄소 베네핏 분해의 기준선 |
| 1. 참조값 | 640 kW 고정 | Furukakoi 2025 — 문헌 비교점 |
| 2. 1차 파일럿 | [0, 836] kW 결정변수 | 2024 동서발전 컨설팅, 자과캠 10개 건물 |
| 3. 옥상+주차장 | [0, 10,305] kW 결정변수 | 옥상PV 전체 13,165 MWh/년을 발전시간으로 역산. 주차장 3곳 포함 |
| 4. +BIPV | [0, 11,208] kW 결정변수 | 3단계 + BIPV 환산 903 kW |

**로버스트 비교**: 하나의 로버스트 목적함수로 집계하지 않는다. 9개 시나리오를 각각 독립적으로
최적화해 $C^*_s$를 구하고, 평균/최고/최악 시나리오가 각각 어느 기후 시나리오인지와 함께 비교한다.
위 5단계 각각에 대해 반복해 **9×5 = 45개 조합**을 만든다.

## 범위

이 LP는 **물리 타당성·방법론 검증용**이다. 공고(기후부 제2026-335호) 기반 사업비·국비 70%·CRF·
NPV를 반영한 **경제성 평가 본체는 조원 모델**(`reference/진우님코드_수정본.txt`)이 담당한다.
여기서는 ESS 용량이 고정이므로 금액을 사업 타당성 수치로 인용하면 안 된다.

결과 수치는 `parameters.md` **(8)절**이 인용 기준이다. 요약하면 present 기준
0단계 158.01억 → 4단계 **145.71억원/년**(−12.30억), 피크 19,409 → **16,114kW**,
탄소 **−6,978 tCO2/년**이다. ESS 운영 효과는 **−1.848억원/년**(피크 −1.285 + 차익거래 −0.813
+ 열화 +0.226 + 탄소 **+0.024**)이고 **탄소는 왕복손실로 증가**한다.

역할 분담·정합성 검토·잔여 계획: `reference/team_review_and_plan.md`

## 결정 필요 사항

- **MG 플랫폼 구축비** — 공고 필수 구축 항목인데 총사업비에서 빠져 있다. 금액 조사 또는 민감도 처리.
- **경부하기 의무충전** — 공고 p.2의 봄 107일 10~16시, 가을 58일 9~16시 ESS 충전 의무는
  파이프라인 6단계에서 검증해 **비구속**(+0.023~0.32%)으로 확인됐다. 조원 모델에는 아직 미반영이다.
