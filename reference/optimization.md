# ESS·PV 최적화 설계

이 문서는 두 LP의 설계다.

- **연구 LP** (`ess_pv_pipeline.ipynb`) — 9개 기후 시나리오(present + SSP1-2.6/2-4.5/3-7.0/5-8.5 ×
  2030s/2050s) 각각에 대해 1년 운영비용을 최소화한다. ESS 용량(`C_ESS`/`C_PCS`)은 고정이고
  **PV 설치용량(`C_PV`)이 결정변수**다
- **경제성 LP** (`econ_model.py`) — present 부하 하나에서 **ESS 출력이 결정변수**이고 PV는 최대용량의
  0~100% 고정점이다. 투자비·국비·25년 현금흐름은 LP 밖에서 계산한다(아래 "경제성 모델")

두 LP는 요금·탄소·열화를 같은 코드(`econ_model.py`)에서 가져온다. 파라미터 값과 출처는
`parameters.md`가 단일 진실 공급원이다.

## 목적함수 (연구 LP)

$$C_s = E_s + D_s + G_s + K_s + P_s$$

**$E_s$ 전력량요금**

$$E_s=\sum_t \pi_t\, P_{grid,t}\,\Delta t,\qquad \pi_t=(Tariff_t + 9 + 5)\times 1.127$$

TOU 요금(경부하/중간/최대 × 계절)에 기후환경요금 9원/kWh + 연료비조정요금 5원/kWh을 더하고
부가세 10% + 전력산업기반기금 2.7%(×1.127)를 곱한다. **학교가 실제로 내는 청구서 구조**이고,
**PV 자가발전분은 이 부가 항목이 전부 면제**되므로 빼면 PV 편익이 과소평가된다.

시간대는 전기공급약관 별표3(교육용전력(을))을 날짜별로 적용한다 — 토요일 최대부하는 중간부하,
공휴일은 종일 경부하, 2026-06-01부터 봄·여름·가을 평일 최대부하 15~21시. 격자 전체는
`parameters.md` (3)절. 경제성 LP는 사업기간(2027~)에 맞춰 **1년 전체를 개편 후 시간대**로 청구한다
(`TOU_BASE`). 연구 LP는 분석연도의 날짜별 시간대를 쓴다.

**$D_s$ 기본요금 — 월별 요금적용전력**

$$D_s = \tau\, c_{peak}\Big(6\,P_S + \sum_{m\notin S} B_m\Big)$$

$$P_m \ge P_{grid,t}\ \ (t \in m,\ t\in\mathcal{D}),\qquad P_S \ge P_m\ \ (m\in S),\qquad
B_m \ge P_m,\ \ B_m \ge P_S\ \ (m\notin S),\qquad P_S \ge 0.3\,P_{contract}$$

$c_{peak}$=6,980원/kW·월, $S$ = {12, 1, 2, 7, 8, 9}월. 기본공급약관 제68조①의 "직전 12개월 중
12·1·2·7·8·9월분 및 당월분 최대수요전력 중 가장 큰 값, 계약전력의 30% 하한"을 매년 같은 운전이
반복되는 정상상태로 옮긴 식이다. 지정월은 요금적용전력이 $P_S$로 같고, 비지정월은
$\max(P_m, P_S)$다.

$\mathcal{D}$는 **중간·최대부하 시간대**다(별표3 2호: 요금적용전력은 중간·최대부하 시간대의
최대수요전력만 대상). 경부하 시간대와 공휴일 수요는 기본요금에 들어가지 않는다. 이 구분이 없으면
ESS가 밤에 충전하면서 만든 수요까지 기본요금으로 잡혀 ESS 가치가 과소평가된다.

`dpnn_benchmark.ipynb`는 같은 $\mathcal{D}$를 쓰되 연중 최대 × 12로 근사한다. 1절에서 월별 방식과의
차이를 출력해 확인한다.

**$G_s$ 열화비용 (cycle aging)**

$$G_s = c_{deg}\sum_t (P_{ch,t,s}+P_{dis,t,s})\Delta t,\qquad c_{deg}=0$$

원장 기준 $c_{deg}$=0이다. 배터리 교체(10·20년차)를 경제성 현금흐름에 따로 넣으므로 운전
목적함수에 throughput 비용을 또 넣으면 **이중계산**이다. 종전 값
$c_{deg}=c_{bat,replacement}/(2N_{EFC})=100{,}000/(2\times5{,}000)=10$원/kWh는 운전 변화 비교용
민감도로만 돌린다.

산출된 SOC 시계열은 **Rainflow counting + Miner's Rule**로 사이클 수명을 사후 검증한다(지도교수 자문).
사이클 기준 수명이 calendar 10년보다 길면 교체 주기는 경과시간이 정하고, 10년 교체 가정이 성립한다
(EFC ≤ 500회/년).

**$K_s$ 탄소비용**

$$K_s = \frac{\sum_t P_{grid,t,s}\Delta t}{1000}\times CO_2^{factor}\times CARBON^{price}$$

배출계수 0.4173 tCO2eq/MWh(국가 승인 2023 소비단 계수), 가격 25,500원/tCO2(발표자료 p.30 SKKU
실적 단가). 타 마이크로그리드 연구 대비 차별점이라 지도교수가 목적함수 포함을 지시했다.

여기 들어가는 값은 **배출권(허가증) 비용**이다. 탄소의 **사회적 비용(SCC, 51·76 USD)**은 성격이
다르므로 목적함수에 넣지 않고, 감축량 × SCC로 사회적 편익을 따로 계산한다.

**$P_s$ PV 설비 연간비용**

$$P_s = c_{pv,annual}\,C_{PV} + C_{BIPV},\qquad
c_{pv,annual}=(1{,}300{,}000+33{,}478)\times CRF + 20{,}000=109{,}929\ \text{원/kW/년}$$

원장 A안(시장 설치단가 + 구조안전진단)을 CRF(4.5%, 25년)=0.06744로 연간환산하고 O&M을 더한다.
$C_{BIPV}$는 4단계에만 붙는 고정비로, 정격 1,274.5kW × (500만원 × CRF + 20,000) = 4.55억원/년이다.

## 제약식 (연구 LP)

- 전력수지: `P_grid − P_curt + P_dis − P_ch + C_PV·p_unit,t = P_load − P_BIPV,t`
  ($p_{unit,t}$ = 1kW 설치 시 단위발전량)
- SOC 동역학 + SOC 범위 20~90%, 상태변수는 $T{+}1$개, 연간 순환(시작 = 끝 50%)
- 충방전 출력 상한 `≤ C_PCS`, 수전 상한 `P_grid ≤ 계약전력 30,000kW`
- 요금적용전력 보조변수: 위 $D_s$의 $P_m$, $P_S$, $B_m$
- PV curtailment 상한: `P_curt,t ≤ C_PV·p_unit,t + P_BIPV,t`
- PV 설비용량 상한: `0 ≤ C_PV ≤ C_PV^max` (0·1단계는 고정값으로 대체)
- 6단계 공고 제약(선택): 대책기간 방전 금지 + 구간 순충전 ≥ level × SOC 가용대역 × `C_ESS`

동시 충방전 금지는 이진변수 제약이지만 효율손실($\eta<1$)로 자연히 발생하지 않음을 검증(위반
0건)해 **구현하지 않고 순수 LP로 푼다.**

## 설비용량 시나리오 (연구 LP)

발표자료 p.41의 자과캠 PV 설치계획(`reference/campus_pv_potential.csv`)을 상한으로 사용한다.

| 단계 | `C_PV` 범위 | 근거 |
| --- | --- | --- |
| 0. PV없음 | 0 kW 고정 | **자과캠 현재 상태.** 탄소 베네핏 분해의 기준선 |
| 1. 참조값 | 640 kW 고정 | Furukakoi 2025 — 문헌 비교점 |
| 2. 1차 파일럿 | [0, 836] kW 결정변수 | 2024 동서발전 컨설팅, 자과캠 10개 건물 |
| 3. 옥상+주차장 | [0, 10,305] kW 결정변수 | 옥상PV 전체 13,165 MWh/년을 발전시간으로 역산. 주차장 3곳 포함 |
| 4. +BIPV | [0, 10,305] kW 결정변수 + BIPV 고정 | BIPV 옥상 등가 903 kW(발전), 정격 1,274.5 kW(비용) |

BIPV는 결정변수가 아니라 고정 설비다 — 설치단가가 옥상의 3.8배(500만 vs 133만원/kW, 정격 기준)라
같은 변수로 묶을 수 없다.

**로버스트 비교**: 하나의 로버스트 목적함수로 집계하지 않는다. 9개 시나리오를 각각 독립적으로
최적화해 $C^*_s$를 구하고, 평균/최고/최악 시나리오가 각각 어느 기후 시나리오인지와 함께 비교한다.
위 5단계 각각에 대해 반복해 **9×5 = 45개 조합**을 만든다.

## 경제성 모델 (`econ_model.py`)

**설비 결정 LP** — 연구 LP와 같은 요금·제약에 ESS 출력 $P_{ess}$를 결정변수로 더한다. 용량은
duration × $P_{ess}$이고, 목적함수는 연간 운영비 + ESS 투자비의 등가연간비용(EAC)이다.

$$\min\ \underbrace{E + D + K}_{\text{운영비}} + c_{deg}\,\text{throughput}
+ \underbrace{CRF\cdot I_{ess} + \text{EAC}(\text{교체}-\text{잔존}) + c_{om}\,h}_{\text{ESS 1kW당 연간비용}}\;P_{ess}$$

$I_{ess}$ = 249,000 + h × 400,000원/kW(기준: BOS 용량 비례). PV 공사비는 전 시나리오 1,300,000원/kW이고
공고 고시단가 1,036,000원은 국비 인정 상한으로만 쓴다. C-2는 학교 관점이라 ESS 투자비에서
국비 몫을 뺀다 — 적격 인정상한(586,000원/kWh) 이내 70%이되, PV·플랫폼 국비를 쓰고 남은 130억 한도까지만
($Z \ge (I_{ess}-0.7\,I^{elig}_{ess})P_{ess}$, $Z \ge I_{ess}P_{ess}-\text{잔여한도}$, 목적함수에 $CRF\cdot Z$).
PV 출력은 열화의 할인가중 대표값 0.9140을 쓴다. PV 투자비는 PV가 고정점이라 LP에 넣지 않는다.

**평가** — 결정된 설계를 고정하고 PV 출력계수 1.0(1년차)·0.7972(25년차)에서 다시 풀어, 연차별
청구액을 출력계수 3점의 2차 보간으로 만든다. NPV는 명시적 현금흐름이다.

$$NPV = -(I_0 - \text{국비}) + \sum_{y=1}^{25}\frac{\Delta\text{전기요금}_y + \Delta\text{배출권}_y
- O\&M_y - \text{교체}_y + \text{잔존}_y}{1.045^{y}}$$

EAC는 설비 결정에만 쓰고 NPV에는 넣지 않으므로 초기투자와 겹치지 않는다. 시나리오(A / C-1 / C-2),
국비 산정, 공고 제약은 `parameters.md` (5)절.

## 범위

연구 LP는 **물리 타당성·방법론 검증용**이다. ESS 용량이 연구용 고정값(6,778kWh)이고 투자비가
없으므로 금액을 사업 타당성 수치로 인용하면 안 된다. **사업 타당성(투자비·국비·NPV·회수기간)은
`econ_model.py`**가 담당하고 결과는 `economics.md`에 있다.

결과 수치는 `parameters.md` **(8)절**이 인용 기준이다.
