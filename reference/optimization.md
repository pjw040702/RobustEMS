# ESS·PV 최적화 설계 (4단계)

9개 기후 시나리오(present + SSP1-2.6/2-4.5/3-7.0/5-8.5 × 2030s/2050s) 각각에 대해 1년 운영비용을 최소화하는 디스패치 LP를 독립적으로 풀고, 그 결과를 비교한다. ESS 용량(C_ESS/C_PCS)은 고정값을 유지하되, **PV 설치용량(C_PV)은 2026-10-28부터 결정변수로 확장**했다(아래 "3단계 설비용량 시나리오" 참고) — 조원 피드백에서 지적된 PV 용량 가정(640kW 고정)이 실제 캠퍼스 포텐셜 대비 지나치게 작았던 문제를 해소하기 위함.

## 목적함수

```
C_s = E_s + D_s + G_s + K_s + P_s
```

- **E_s (전력량요금)** = Σ_t Tariff(t) · P_grid,t,s · Δt — TOU 요금(경부하/중간부하/최대부하 × 계절)
- **D_s (기본요금/피크)** = **12** · c_peak · P_peak,s — **연간 최대수요전력 기준**(결정 완료). `P_peak,s ≥ P_grid,t,s` (연중 전체 t) 제약으로 max()를 선형화 → **15분 피크전력이 여기서 비용에 직접 반영됨**
  - **×12 수정(2026-11-05)**: c_peak=6,980원/kW는 교육용(을) 고압A의 **월** 단가인데 다른 항은 모두
    연간 금액이어서, 이전 구현(×1)은 피크 감축 가치를 1/12로 과소평가하고 있었다. 래칫(연중 최대피크가
    12개월 적용)을 반영해 ×12로 수정 — 조원 지적이 맞았다. 설치 전 기준 1.43억 → 17.14억원/년.
    조원 검증으로 ×1이면 PV 비율과 무관하게 최적 ESS가 0으로 나와 결론 자체가 달라짐이 확인됨.
- **G_s (열화비용, cycle aging만)** = c_deg · Σ_t (P_ch,t,s + P_dis,t,s) · Δt
  - `c_deg = c_bat,replacement / (2 × N_EFC) = 100,000 / (2 × 5,000) = 10원/kWh-throughput` (Gasper et al. 2023, LFP/Graphite 4,000~6,000 EFC 범위의 기준값, SOH 80% 기준)
  - **최적화 단계는 이 throughput 선형 근사만 사용** — 지도교수 자문: 산출된 SOC 시계열은 이후 **Rainflow counting + Miner's Rule**로 실제 수명을 **사후 검증**(LP 목적함수에는 포함하지 않음)하는 2단계 방식으로 진행
  - **사후검증 완료(2026-10-30, 수치는 2026-11-05 SOC 수정 반영)**: 27개 시나리오x단계 조합
    전부에서 Rainflow 기준 EFC가 throughput 선형근사 대비 **-0.43%**(전 조합 동일)로 일치 →
    c_deg·N_EFC 재조정 불필요. 단 f(DoD)=DoD 선형 손상 가정에서는 두 지표가 수학적으로 거의
    같은 양이므로, 이 수치는 선형 가정의 검증이 아니라 구현 일관성 확인에 가깝다.
  - **실질 성과는 수명 비교**: 사이클 기준 추정수명 **28.3~28.4년** > calendar life **10년**
    → **수명은 사이클이 아니라 경과시간이 결정**한다. 따라서 (a) N_EFC 민감도는 비구속이므로
    우선순위 하향, (b) 교체비를 10년 연간환산으로 넣으면 c_deg를 비용 합계에 다시 더하는 것은
    이중계산 — 조원 경제성 모델의 "c_deg는 운전 판단에만, 합계에서 제외" 처리가 타당함을 뒷받침.
    (상세는 `ess_pv_pipeline.ipynb` 5단계)
  - Calendar aging은 운전 결정과 거의 무관(경과시간 위주)해 LP에서 제외 — 전체 경제성 평가 시 별도
    고정비용으로 반영(**결정 완료: 단순 선형식 채택**) `C_calendar ≈ c_bat,replacement × (t / L_calendar)`,
    `L_calendar`≈10년(Xu et al. 2024). SOC·온도 기반 정교 모델은 검증단계용으로 보류.
- **K_s (탄소비용)** = (Σ_t P_grid,t,s · Δt)/1000 · CO2_FACTOR · CARBON_PRICE
  - 지도교수 강조사항(타 마이크로그리드 연구 대비 차별점)으로 목적함수에 포함하기로 확정
  - 배출계수 = **0.45941 tCO2eq/MWh**, CARBON_PRICE = **25,500원/tCO2** — 둘 다 SKKU 캠퍼스
    탄소중립 발표자료(탄소중립연구소, 2026-10-08) 공식값으로 2026-10-28 확정(조원이 전달했던
    0.4173, 기존 KAU 시장가 29,450원과 불일치가 확인되어 교체). 상세 출처는 `parameters.md` 참고.
  - 계약·환경가치 반영 배출계수·한계배출계수는 2026-10-16 미팅에서 검토했으나, 지도교수 자문에
    따라 이번 연구 범위에서는 불필요한 것으로 확인되어 반영하지 않음
- **P_s (PV 설비 연간비용)** = c_pv,annual · C_PV
  - c_pv,annual = **141,848원/kW/년** — 2026-11-06 발표자료 p.53 기준으로 교체
    (순설비비 2,021,531 + 구조안전진단 29,443)/25년 + O&M 59,809. 기존 조원 조사값
    (130만−보조금 53만, O&M 1.75만 ≈ 48,300원)의 2.9배. 상세 `parameters.md` (2)·(14)절
  - C_PV는 1단계(현재)에서는 640kW 고정, 2·3단계에서는 결정변수(아래 참고)

**3단계 설비용량 시나리오(결정 완료, 2026-10-28)**: SKKU 캠퍼스 탄소중립 발표자료(41p)의 자과캠

## 제약식 (쓰이는 것)

- 전력수지: `P_grid − P_curt + P_dis − P_ch + C_PV·p_unit,t = P_load` (p_unit,t = 1kW 설치시 단위발전량)
- SOC 동역학 + SOC 범위(20~90%)
- 충방전 출력 상한(≤ C_PCS) + 동시 충방전 금지
- 피크 보조변수 선형화(연간 기준): `P_peak ≥ P_grid,t` (∀t, 연중 전체)
- PV curtailment 상한(가변): `P_curt,t ≤ C_PV·p_unit,t`
- PV 설비용량 상한: `0 ≤ C_PV ≤ C_PV^max` (1단계는 고정값으로 대체)

수식·파라미터 값은 `parameters.md` 참고.

NPV를 반영한 **경제성 평가 본체는 조원 모델**(`reference/진우님코드_수정본.txt`)이 담당한다.

## 목적함수 통일 (2026-11-06)

`dpnn_benchmark.ipynb` 와 목적함수를 통일했다. $E_s$·$D_s$ 에 **청구서 부가 항목**이 들어간다.

$$E_s=\sum_t (Tariff_t + 9 + 5)\times 1.132 \cdot P_{grid,t}\Delta t,\qquad
D_s = 12\times 1.132\, c_{peak} P_{peak}$$

기후환경요금 9원/kWh + 연료비조정 5원/kWh에 전력산업기반기금 3.2% + 부가세 10%(×1.132)가
붙는다. 학교가 실제로 내는 청구서 구조이고, **PV 자가발전분은 이 항목이 전부 면제**되므로
빼면 PV 편익이 과소평가된다. 상세는 `parameters.md` (13)절.


## 최종 수치 (2026-11-06)

모든 인용 수치는 `parameters.md` **(14)절**을 기준으로 한다. 요약하면 present 기준
0단계 158.01억 → 4단계 **145.71억원/년**(−12.30억), 피크 19,409 → **16,114kW**,
탄소 **−6,978 tCO2/년**이다. ESS 운영 효과는 **−1.848억원/년**(피크 −1.285 + 차익거래 −0.813
+ 열화 +0.226 + 탄소 **+0.024**)이고, **탄소는 왕복손실로 증가**한다.

자기방전(Elalfy 2024, 5%/month)을 SOC 동역학에 반영했다 — $E_k=(1-\delta)E_{k-1}+\dots$,
$\delta=0.05/(30\times96)$. 영향은 throughput의 0.06%다.
