`CARBON_PRICE`는 **배출권(허가증) 비용**이다. 탄소의 **사회적 비용(SCC)**은 외부효과의 사회적
가치로 성격이 다르므로 **목적함수에 넣지 않고** 서술에서 구분만 한다(지도교수 지시).

**배출권은 무상할당 초과분만 부담한다.** 발표자료 p.30의 자과캠 인벤토리:

| 구분 | 2023 | 2024 | 2025 |
| --- | --- | --- | --- |
| 배출량 (tCO2eq, Scope 1+2) | 45,407 | 45,759 | **46,426** |
| 무상할당량 | 48,532 | 47,412 | 47,655 |
| **구매필요량** | 6,784 | 8,524 | **9,226** |
| 실제 매입단가 (원/tCO2) | 9,010 | 8,800 | **25,500** |
| 실제 구입비용 | 0.61억 | 0.75억 | **2.35억** |

- `K_s`는 전체 배출량 기준이라 **실제 지출의 약 5배**다(0단계 11.32억 vs 실적 2.35억).
  보고서에서 `K_s` 레벨을 "학교가 내는 탄소비용"으로 제시하면 **틀린다**
- **한계 의사결정에는 유효하다** — 무상할당을 초과한 상태이므로 1 tCO2 감축 = 구매 1 tCO2 감소
- **한계편익에 상한이 있다** — 감축량이 9,226 tCO2를 넘으면 초과분 편익은 0. 현재 PV 최대 감축은
  6,978 tCO2로 범위 내다(잔여 2,248)

   없으므로 이 둘이 ESS 가치의 전부다
2. **차익거래 효과는 PV 규모와 무관하게 일정**(−0.808 ~ −0.813억)하지만 **피크 효과는 PV가
   커지면 같이 커진다**(−0.997 → −1.285억). PV와 ESS는 **피크 채널에서 보완적**이고 차익거래
   채널에서는 독립적이다
3. **ESS는 탄소를 줄이지 않고 늘린다**(Δ`K_s` = +0.024억/년 = 연 약 90 tCO2). 왕복효율 83%라
   17% 손실만큼 한전에서 더 사야 한다. **"ESS = 탄소 감축 수단"으로 서술하면 틀린다** —
   탄소 감축은 PV의 몫이고, 카본 베네핏 분해에서 이 부호를 반드시 분리해야 한다
4. **열화비용 +0.226억**은 목적함수에 든 운전 판단용 비용이다. 경제성 합계에 교체비를 따로
   넣는다면 이 항은 빼야 한다(이중계산, 10절)

> **투자비는 이 표에 없다** — 운영 효과만이다. 사업 타당성은 조원 경제성 모델이 담당한다.

| `k_cal` (SOC·온도 기반 calendar 열화율) | **미정** | 출처 미확보. 단순 선형 근사로 대체(10절) |

## (10) 모델 수식

### ESS 등가회로 모델 (ECM)

배터리 내부의 화학적·전기적 동작을 R(저항)·C(커패시터) 회로 요소로 변환해 내부 손실과 전압
강하를 정량화한다.

- $V_{oc}$ 개방회로 전압(SOC의 함수)
- $R_0$ 내부 오믹 저항(전류 흐름 시 열 손실 발생 원인)
- $R_p$, $C_p$ 분극 저항·커패시턴스(과도 응답 특성)
- 전력 손실 $P_{loss}(t) = I(t)^2 R_0$

→ 충·방전 시 내부 저항으로 사라지는 에너지를 실제 충방전 효율 $\eta_{ch},\eta_{dis}$로 반영한다.
현재 모델은 C-rate 0.2C라 평탄한 왕복효율을 쓴다.

### 핵심 물리 변수

| 변수 | 기호 | 단위 | 설명 |
| --- | --- | --- | --- |
| SOC | $SOC(t)$ | % | 배터리 잔존 용량 (State Of Charge) |
| SOH | $SOH(t)$ | % | 배터리 수명 상태 (State Of Health) |
| DoD | $DoD(t)$ | % | 방전 깊이 = $100 - SOC$ |
| C-rate | $C_{rate}$ | C | 용량 대비 충방전 속도 |
| 충방전 전력 | $P_{ch}(t), P_{dis}(t)$ | kW | |
| 충방전 효율 | $\eta_{ch},\eta_{dis}$ | — | 내부 저항·변환 손실 반영 (통상 0.9~0.95) |
| PCS 정격 | $C_{PCS}$ | kW | 배터리(DC)와 AC 계통 사이 변환 장치 용량 |

### SOC 동역학과 제약

$E$는 구간 **경계**의 상태량이라 $T{+}1$개($E_0 \sim E_T$)를 둔다. 이렇게 해야 $T$개 구간의
충·방전이 전부 에너지수지에 반영된다($T$개로 두면 $t=0$ 충방전이 어떤 제약에도 걸리지 않아
LP가 '공짜 에너지'를 만든다).

$$E_k=(1-\delta)E_{k-1}+\eta_{ch}\Delta t\,P_{ch,k-1}-\frac{\Delta t}{\eta_{dis}}P_{dis,k-1},
\qquad \delta=\frac{0.05}{30\times 96}$$

$$SOC_{min}C_{ESS}\le E_t\le SOC_{max}C_{ESS},\qquad
DoD=\frac{E_{max}-E_{min}}{C_{ESS}}$$

$$0\le P_{ch,t}\le C_{PCS},\qquad 0\le P_{dis,t}\le C_{PCS},\qquad 0\le C_{ESS}\le C_{ESS}^{max}$$

동시 충방전 금지는 원래 $P_{ch,t}\le P_{ch}^{max}u_{ch,t}$, $P_{dis,t}\le P_{dis}^{max}u_{dis,t}$,
$u_{ch,t}+u_{dis,t}\le 1$로 쓰지만 LP 해에서 위반이 0건이므로 구현하지 않는다.

### ESS 열화

$$D_{total}=D_{cycle}+D_{calendar}$$

열화비용은 배터리를 쓸 때마다 실제로 지불하는 요금이 아니라, 사용으로 줄어든 수명만큼 미래
교체비용의 일부를 현재 사용에 배분한 값이다. 고려하지 않으면 전기요금을 아끼려고 ESS를 지나치게
자주 충방전하게 된다. 최적화 단계에서는 **Cycle aging(throughput 선형 근사)만** 반영하고,
도출된 SOC 시계열을 **Rainflow counting + Miner's Rule**로 사후 검증하는 2단계 방식을 쓴다
(지도교수 자문).

**1. Cycle aging — 목적함수에 포함**

$$E_{throughput}=\sum_t(P_{ch,t}+P_{dis,t})\Delta t,\qquad
C_{cycle}=c_{deg}E_{throughput},\qquad
c_{deg}=\frac{c_{bat,replacement}}{2N_{EFC}}$$

$$Q=\int_{t_0}^{t}|I(t)|\,dt,\qquad FEC=\frac{Q}{2C_{batt}}$$

충전량과 방전량을 모두 합산하고 효율 손실을 무시한 선형 근사다. discharge depth와 cycle count의
관계를 충분히 반영하지 못할 수 있어 아래 Rainflow로 사후 검증한다.

| 파라미터 | 의미 | 기준값 | 민감도 | 출처 |
| --- | --- | --- | --- | --- |
| $c_{bat,replacement}$ | 단위 용량당 교체비용 | 100,000 원/kWh-capacity | — | Gasper 2023 |
| $N_{EFC}$ | EOL까지 등가완전사이클 | **5,000** (LFP/Graphite 4,000~6,000, SOH 80% EOL) | 비구속 | Gasper 2023 |
| $c_{deg}$ | 단위 throughput당 비용 | **10** 원/kWh-throughput | 8.3~12.5 | 계산값 |

**2. Calendar aging — 경제성 평가에 별도 고정비용으로 반영(LP 제외)**

$$C_{calendar}\approx c_{bat,replacement}\times\frac{t}{L_{calendar}}$$

Calendar life 동안 수명 소모가 선형이라는 단순 근사다($L_{calendar}$ ≈ 10년, Xu et al. 2024,
상용 LFP 기준). 이 값만으로 SOC·온도에 따른 실제 열화속도를 확정할 수는 없다. SOC·온도 기반
정교 모델 $D_{calendar}=\sum_t k_{cal}(SOC_t,T_{bat,t},age_t)\Delta t$는 $k_{cal}$ 출처가
없어 보류한다. 고정비용으로 두면 **고정 용량의 시간별 운전 최적화에는 영향이 없다.**

**3. Rainflow counting — 사후 검증용(LP 미포함)**

$$DoD_i=SOC_{peak,i}-SOC_{valley,i},\qquad D_{cycle}=\sum_{i=1}^{N}n_i\,f(DoD_i)$$

$SOC_{peak,i}$는 증가하다 감소하기 시작하는 지점(local max), $SOC_{valley,i}$는 그 반대다.
$n_i$는 사이클 횟수(full cycle $n=1$, half cycle $n=0.5$), $f(DoD_i)=DoD_i$(선형 손상함수)를
쓴다. 흐름: SOC 시계열 → Rainflow(`rainflow` 패키지, ASTM E1049-85)로 각 사이클의 DoD·횟수 →
Miner's Rule로 열화량 → 잔존용량·수명 검증.

**해석 주의** — 선형 손상함수에서는 Rainflow EFC $\sum_i n_i DoD_i$와 throughput EFC가 수학적으로
거의 같은 양이므로, 괴리율(−0.43%)은 **선형 가정 자체의 검증이 아니라 두 구현의 일관성 확인**에
가깝다(잔차는 충방전 효율·경계 처리에서 발생). DoD별 손상의 실제 비선형성은 이 테스트로 답할 수
없다. **실질 성과는 수명 비교**(사이클 30년 ≫ calendar 10년)다.

**모델 적용 시 주의**

1. Cycle aging(5,000 EFC)과 Calendar aging의 수명값에는 실험기간 중 상호영향이 일부 포함돼 있을
   수 있어, 두 교체비용을 단순 합산하면 열화를 **과대평가**한다
2. Calendar aging을 사용기간 비례 고정비용으로 두면 디스패치 최적화에는 영향이 없다
3. 열화비용은 수명 소모를 경제적으로 환산한 값이므로, 장기 경제성 평가에서 **실제 교체비용과
   중복 합산하지 않는다**

### PV

$$0\le C_{PV}\le C_{PV}^{max},\qquad P_{PV,t}=C_{PV}\,p_{unit,t}$$

$$P_{DC,t}=C_{PV}\frac{G_t}{G_{STC}}\big[1+\gamma(T_{cell,t}-T_{STC})\big]\eta_{sys},
\qquad T_{cell,t}=T_{amb,t}+\frac{NOCT-20}{800}G_t$$

$$0\le P_{curt,t}\le P_{PV,t}^{avail},\qquad P_{PV,t}=P_{PV,t}^{avail}-P_{curt,t}$$

$p_{unit,t}$는 1kW 설치 시 단위 발전량이다. 다년도 열화는
$P_{PV,t,y}=P_{PV,t,0}(1-d_{PV})^y$이나 1년 정적 모델이라 쓰지 않는다.

### 전력수지와 비용

$$P_{grid,t}+P_{PV,t}+P_{dis,t}=P_{load,t}+P_{ch,t}+P_{curt,t},
\qquad P_{grid,t}\ge 0,\ P_{curt,t}\ge 0$$

$$C_s=\underbrace{\sum_t\pi_t P_{grid,t}\Delta t}_{E_s}
+\underbrace{12\,\tau\,c_{peak}P_{peak}}_{D_s}
+\underbrace{c_{deg}E_{throughput}}_{G_s}
+\underbrace{\frac{\sum_tP_{grid,t}\Delta t}{1000}CO_2^{factor}\,CARBON^{price}}_{K_s}
+\underbrace{c_{pv,annual}C_{PV}}_{P_s}$$

$\pi_t=(Tariff_t+9+5)\tau$, $\tau=1.132$. 피크는 $P_{peak}\ge P_{grid,t}$ (∀t, 연중 전체)로
선형화한다 — 15분 피크전력이 비용에 직접 반영된다. 설계 상세는 `optimization.md`.

### 결정변수와 역할

| 기호 | 역할 |
| --- | --- |
| $C_{PV}$ | **결정변수** — 2~4단계는 $[0, C_{PV}^{max}]$, 0·1단계는 고정 |
| $P_{grid,t}$, $P_{ch,t}$, $P_{dis,t}$, $P_{curt,t}$, $E_t$, $P_{peak}$ | **결정변수** |
| $P_{load,t}$, $G_t$, $T_{amb,t}$, $Tariff_t$, $\Delta t$ | 입력 |
| $C_{ESS}$, $C_{PCS}$ | 고정(조원 모델이 용량 최적화를 담당) |
